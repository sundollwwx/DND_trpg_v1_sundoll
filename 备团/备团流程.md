# 备团流程（工程化标准）

> 适用于「桑哆尔的世界」项目下的所有备团协作。每次开新团，按此流程执行。
> 模板文件在本文件夹的 `模板/` 子目录里。

## 一、开工前确认（每次必问；没答的部分用合理假设并注明）

- 玩家人数
- 起始等级与升级节点（幕间升级 / XP / 村规）
- 幕（场景）数量与大致内容
- 剧情基调（正剧 / 黑色幽默 / 轻松）
- 特殊要求：命名、村规、难度偏好

## 二、团文件夹结构（标准，新建团照此建）

```
桑哆尔的世界/
├── 短团·<团名>/               # 或 长团·<团名>
│   ├── 剧情·<团名>.html       # 完整叙事（备团通读，是内容"源"）
│   ├── 速查卡·<团名>.html     # 临场速查（4 列卡片 + 点击放大）
│   ├── maps/                  # .地图.json，与主控台格式一致
│   └── gen_maps.py            # 地图生成脚本（可复现、可改）
└── _备团模板/                 # 模板与流程（本文件所在处）
```

## 三、制作顺序（固定）

1. **剧情大纲**：主线 + 每幕一句话 + 伏笔，先给用户确认。
2. **地图**：脚本生成 → 验证格式 → 放入团文件夹 `maps/`。
3. **剧情 HTML**：从「剧情模板」生成完整叙事——故事梗概、等级节奏、关键人物（含台词库）、各幕细节（开场白/遭遇/站位/分支）、结局分支、后日谈、检查单。**剧情文件是内容源。**
4. **速查卡 HTML**：从「速查卡模板」生成，从剧情文件提炼台词 / 配置 / 站位 / 分支 / 战利品 / 敌人属性，拆成 4 列卡片。
5. **同步**：地图副本放进主控台 `maps/`；团文件夹整体放进「桑哆尔的世界」。
6. **验收**：对照下方检查单逐项打勾。

## 四、验收清单

### 地图

- [ ] JSON 字段：`app=dnd-board`、`kind=map`、`gridSize=50`
- [ ] `mapW = 列数×50`、`mapH = 行数×50`
- [ ] 所有 tile id 都在地图工坊的 TILES 集合内
- [ ] `cellStates` 只指向可交互格（door / gate / chest / trap / torch）
- [ ] 主控台 `maps/` 已有副本

### 剧情 HTML

- [ ] 故事梗概 + 等级节奏表
- [ ] 关键人物（含台词库）
- [ ] 每幕：开场白、环境描写、遭遇配置、站位、分支
- [ ] 结局分支 + 伏笔
- [ ] 备团检查单

### 速查卡 HTML

- [ ] 固定 4 列卡片布局（窄屏 2 列 / 手机 1 列）
- [ ] 每张卡片未点击即展示详细内容，点击放大（modal）
- [ ] 角色台词已并入对应幕的分组
- [ ] 敌人属性表、决策点、后日谈齐全
- [ ] 打印样式（Cmd/Ctrl + P 白底分页）

### 一致性（必查）

- [ ] 速查卡与剧情 HTML 的台词、数值、站位、分支完全一致
- [ ] 修改任意一处后，另一文件同步更新

## 五、命名规范

- 地图：`<场景>·<地名>.地图.json`
- 剧情：`剧情·<团名>.html`
- 速查卡：`速查卡·<团名>.html`

## 六、跑团中与跑团后

- 用户报告进度 → 按当前幕提供速查、难度调整、分支建议。
- 跑团结束 → 把实际发生的结局 / 分支回填到剧情 HTML（标注"实跑记录"），并同步速查卡，供后续团参考。
