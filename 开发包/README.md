# 开发包

这里是开发与维护工具，不参与日常开团。当前产品结构以 [目录导览](../程序包/目录导览.md) 为准；账号与角色规则以 [账号与角色规则](../程序包/账号与角色规则.txt) 为准。

## 当前入口

| 工作 | 使用入口 |
| --- | --- |
| 全量回归 | `maintenance/check_project.py --node /绝对路径/node` |
| 当前游戏发行 | `build_distribution_v4.py --help` |
| 本机备份与恢复 | 根目录统一启动器 `--backup` / `--restore` |
| 历史存档只读审计 | `maintenance/audit_historical_saves.py` |
| 特定数据修复 | [维护工具说明](maintenance/README.md)，先预览再应用 |
| 主站发布 | [网站说明](../网站/README.md) |
| 邮箱与服务配置 | [部署与维护](docs/部署与维护.md) |

## 目录职责

- `tests/`：隔离存档的 Python 和 JavaScript 回归测试。
- `maintenance/`：日常检查、核对与针对性修复工具。
- `github/`：仓库同步辅助工具；不是玩家入口。
- `docs/`：当前功能与维护说明。
- `生活玩法/`：从公开默认规则导出生活玩法文档的脚本，不是另一套存档。

设计草稿、历史验收、代码恢复点、修复备份和发行候选由维护者在本机另行保存，不随公开源码提供，也不能作为当前功能已经实现或线上已经发布的依据。

`build_distribution_v3.py` 只提示使用当前构建器；v3/v4 的迁移、激活及验证脚本用于旧格式接入，不要对现有安装重复执行。桌面原型开发已暂停，对应源码和打包工具不在公开交付范围内。

本次精简及可恢复位置见 本地 `维护记录/项目精简-20261017/完成与验证.md`（不随源码发布）。旧维护记录可能描述已删除的个人离线版，均不再作为当前使用方式。

原工作区归档后，测试资料统一读取 `../程序包/主程序/defaults/日常小事/`，不读取作者的正式房间或历史归档。空白发行只使用公开 defaults；标准发行的 `--source` 须明确选择隔离来源并审阅通用内容。历史核查默认选择唯一房间，多房间时使用 `--save-root` 明确指定。
