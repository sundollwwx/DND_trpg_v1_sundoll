# GitHub 同步

macOS 双击 `.command`，Windows 双击 `.bat`：

- `一键上传GitHub`：只上传公开程序源码、网页、默认规则与界面素材。远端领先或分叉时停止，先正常合并。
- `一键从GitHub覆盖本地`：确认后更新公开源码，更新前建立本地源码备份分支。本机账号、角色、房间存档、密钥、备份和其他私人文件均保留。

两个方向共用 `public_source.py` 的允许清单，不依赖 `.gitignore` 来决定私人数据是否能上传。未知路径、符号链接、子模块、仍跟踪私人数据的旧 HEAD 或索引会使操作停止。下载不会递归清理整个目录。旧版包含存档的仓库须先完成源码分离，不能直接用本工具覆盖。

`public_path(name)` 检查相对 POSIX 路径；`candidate_files(root)` 返回可发布的普通文件清单。暂停的桌面客户端、制作原稿、历史记录和本机运行数据不在源码发布范围内。此清单控制路径；新增源码仍应审查，不能在程序源码中硬编码密钥。

程序从自身路径定位项目根目录，不以当前终端目录作为仓库。只查看状态可在项目根目录运行 `python3 开发包/github/github_sync.py check`；这个命令不联网、不上传、不覆盖。
