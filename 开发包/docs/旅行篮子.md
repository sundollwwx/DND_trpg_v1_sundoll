# 旅行篮子

主控点击地图左下角「旅行篮子」打开居中的皮肤预览窗口，点缩略图应用并展开篮子；返回、Esc 或点击遮罩关闭窗口。旁边的小箭头单独展开或收起篮子。玩家端没有主动展开、收起或换肤入口；仅在主控展开时显示，收起时隐藏整个篮子。拖动棋子不能绕过主控开关。把地图上的棋子拖到俯视底板（或收起状态的篮子按钮）即可收起，目标会高亮；换到目标地图后，将底板里的棋子拖到地图上的目标位置下车，点击不会放出；松在篮子内、地图外或取消拖动时保留在篮子。皮肤由主控选择，保存在当前战役并同步给玩家，玩家端没有皮肤切换入口。拖入篮子不计作地图移动。

主控可收放当前地图中的玩家棋子和 NPC。玩家只看到自己档案已上场或已收起的棋子，支持远程收回，不能把棋子放到未开放地图。未上场的收藏仍从个人棋子库带入。每枚棋子在地图与篮子间移动，不复制；血量、临时生命值、状态、形态和身份保留。上车会解除骑乘并退出先攻，其他骑手留在原图。

篮子属于当前战役，跨地图保留并随战役存档恢复。玩家棋子复用 `parkedOwnedPieces` 保留属性，以 `travelBasketStored=true` 区分旅行收纳与普通回库；普通 NPC 保存于 `travelBasketTokens`。它与跨战役的个人物品背包不同。

玩家篮子列表通过已登录的玩家会话读取，只返回必要的名称与头像，不暴露其他玩家、隐藏地图名称或主控私密状态。篮子收起时停止定期查询；展开时每 12 秒校验一次，标签页后台时暂停定期查询。重复渲染棋子不会触发查询。

皮肤为 ImageGen 生成的通用俯视场地，中央留空承载棋子，装饰集中在边缘。当前按路面（古城石道、林间小径、雪地足迹、乡野土路、荒漠沙地、山地险径、沼泽泥径、海岸沙滩、洞窟岩地、地牢石板、木质栈道、火山焦土）、载具（旅行马车、远航帆船）、传送门（奥术星环）三组展示十五款皮肤，使用保留透明通道的 WebP，每张约 180–620 KB。旧版马车、道路、帆船已从菜单与应用素材中移除；旧道路存档映射到古城石道，旧马车映射到旅行马车、旧帆船映射到远航帆船。圆形星环使用正方形画布及圆形命中区域，透明角落不能收纳棋子；棋子布局限制在内圈。皮肤选择与展开状态（`travelBasketOpen`）随战役保存、加载并广播给玩家；旧存档默认收起。

## 六枚棋子容量验收

所有已启用皮肤按三列排列。头像使用随面板宽度缩放的尺寸，名字固定一行；前六枚棋子必须同时可见、不重叠、不需要滚动。超过六枚仍可滚动收纳区。2026-09-21 使用六个不同身份的临时 NPC 验证了主控马车，304px 与 260px 两种面板宽度均通过边界及重叠测量。

「远航帆船」已接入并通过六席验证，采用 `aspect-ratio:2`、图片 `object-fit:cover`（仅裁透明上下留白）、收纳区 `inset:27% 28% 20% 14%`、头像 `clamp(16px,8cqw,26px)`。304px 与 260px 面板均可完整显示两排三枚。该款已加入正式载具分类。


2026-09-21 九款新路面已全部接入，使用统一的中央六棋子区域。逐款浏览器验证图像加载、六枚完整显示、不重叠；全部十五款皮肤均验证保存字段恢复及玩家端可用。运行素材位于 `程序包/主程序/asset/界面/旅行篮子`，原图与待审核图位于 `创作包/界面设计/旅行篮子`。战役仅保存 `travelBasketSkin` 标识，完整皮肤库由主程序共享，无需向每个战役复制图像。


拖放命中区域按皮肤透明通道采样，帆船裁切也按相同的图片缩放换算；透明边缘可作为地图放出位置，实心底板及工具按钮阻止放出。拖动头像中心对齐指针，绿色边框表示可放到地图，红色表示不可放置；最终位置仍遵守网格吸附与空位规则。


删除与旅行收纳分离：Delete/普通删除仅移除地图棋子；玩家棋子保留完整属性回到个人棋子库，普通棋子实例删除。只有明确拖入篮子才设置 `travelBasketStored=true`；普通回库设置为 false。旧版未标记的玩家收起记录保留在库中，不自动列入篮子。服务器篮子查询、从篮子放出验证、主控联机同步都使用这一标记。
