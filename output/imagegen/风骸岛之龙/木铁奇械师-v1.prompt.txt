初次生成 Prompt
================

Use case: stylized-concept
Asset type: D&D跑团地图棋子人物全身立绘
Primary request: 一名由金属和木头制成的男性气质人形机器人奇械师，双手装有可切换的多功能工具
Subject: 单个完整的人形构装体，约正常成年人的身高，体格结实但不像重型战斗机甲。身体内部是深色胡桃木骨架与雕刻木质躯干，外部覆盖磨旧的黄铜、青铜和深灰钢铁护板；关节处能看见清晰的轴承、齿轮、铆钉与皮革缓冲垫。木材纹理与金属材质各占明显面积，结构可信，像由奇幻工坊精心制造。
Head and expression: 头部为有人格感的机械面孔，深色木质面罩配金属眉骨、下颌和耳侧齿轮，两只温暖的琥珀色镜片眼睛。表情专注、聪明、沉稳，不能像无脸头盔、骷髅或可爱玩具。
Artificer identity: 胸口嵌有一个小型蓝白奥术动力核心，亮度克制；腰间佩戴整齐的工具带、量尺、零件小袋和一两枚备用齿轮，身上有简洁的皮革工匠半围裙与护目镜结构，清楚表现他是一位奇械师而不是普通士兵。
Tool hands: 只有两条手臂，绝不增加手臂。两只前臂都装有精密的旋转式工具接口与折叠工具架。画面中一只手的末端切换成精巧的黄铜夹钳/机械抓手，另一只手的末端切换成短小的奥术旋转钻与螺丝刀组合头；小锤、扳手、锉刀等备用工具头整齐折叠并贴合在前臂侧面，明确表现“手可以切换多种工具”。每只手只启用一种工具形态，结构清楚，不像多余手指或多条胳膊。不要枪械。
Pose: 侧前方四分之三视角，稳定自然的工匠站姿。一只工具手抬至胸前展示正在旋转切换的工具接口，另一只工具手略向外伸，像刚完成精密调整；双脚站稳，动作专注且有工作感。完整展示头部、胸腔、两条手臂、两个工具接口、腰间工具带、双腿和双脚。
Style/medium: 高质量西幻规则书人物插画，细腻厚涂写实，奇幻构装体设计，材料磨损与体积明确，自然可信的机械结构；不是照片、动漫、Q版或现代科幻3D机甲。
Color palette: 深胡桃木棕、旧黄铜金、暗灰钢为主，皮革棕为辅，蓝白奥术核心与琥珀眼睛作为少量清晰焦点。
Composition/framing: 1:1正方形，单个机器人完整全身。画布中央为完整的浅暖旧纸色圆形底板，直径约占画布86%，圆外均匀纯白。头顶、脚底、全部工具头与任何微弱奥术光必须完整位于圆形底板内并留安全余量。圆边干净，无厚重装饰环或场景。
Small-size readability: 192×192时看清木材与金属分区、两只不同工具手、胸口核心；64×64时仍能辨认人形机器人、奇械师工具轮廓和木铜双色。优先清楚剪影和大材质色块，不依赖细碎齿轮。
Constraints: 只出现一个机器人奇械师；只有两条手臂和两条腿；木头与金属都明显；手部工具可切换；工具与关节结构合理；无文字、UI、签名、水印、多格排版、裁切。
Avoid: 人类皮肤、额外人物、多臂、六只手、重复工具手、现代工业机器人、科幻枪械、激光炮、巨大武器、车辆、完整工坊场景、密集蒸汽遮挡、过多微小零件、骷髅脸、玩具感、文字、水印。

============

Use case: precise-object-edit
Input images: Image 1 is the newly generated wood-and-metal artificer robot portrait and the edit target.
Primary request: 只修正棋子构图与背景。将完整机器人和所有工具整体缩小约12%并居中，使护目镜顶端、头部、夹钳、钻头、工具架、双脚和所有微弱奥术光都完整位于中央浅暖旧纸色圆形底板内，并与圆边保留清楚安全余量。

Constraints: 严格保留同一个奇械师机器人的木质面罩、胡桃木骨架、黄铜青铜与深灰钢甲、琥珀镜片眼睛、蓝白胸口核心、皮革围裙和工具带、两条手臂、左侧夹钳工具手、右侧奥术钻头工具手、折叠工具架、站姿、材质、光照和西幻规则书厚涂风格。只改变整体缩放、位置、留白和圆外背景。
Avoid: 改造机器人、改变工具手、增加手臂、增加工具、裁切、身体或工具越过圆边、黑色外围、透明外围、文字、水印。
