# 桑哆尔之歌主站

公共素材缓存由 `程序包/主程序/shared/ui-assets-cache.js` 和 `ui-assets-sw.js` 共用实现，构建时生成主站图片清单及内容哈希地址。页面加载后在空闲时间串行准备背景、Logo、拼图等图片，之后优先读取浏览器 Cache Storage；节省流量模式和 2G 环境不主动预下载。只缓存清单内的公共图片，HTML、账号、留言和战役接口继续联网。更新清单后清理旧版本；缓存不可用或空间不足时仍能正常加载，空间不足会停止后台准备。此机制缓存素材，不提供整站离线登录或离线联机。

全站功能配色的唯一源码是 `程序包/主程序/shared/design-system.css`。账号页、DM、玩家端与素材编辑器直接引用；`build_site.py` 将同一份样式打入主站的哈希 CSS，不新增跨域加载依赖。主站以墨绿、暖灰和旧金保持统一；角色、房间、物品、资料、世界、管理在同一低饱和色系里使用细微底色差，状态与稀有度颜色保持独立。

`主站/` 是独立发布到 Cloudflare Pages 的静态门户，包含首页、关于页、费伦日报、骰子、拼图和酒馆传声。静态主站、公告、互动与公开留言读取不依赖本机跑团服务；邮箱注册、登录、房间操作和写留言需要本机账号服务运行，公网访问还需要隧道连通。留言保存在 Cloudflare Worker 的 D1 数据库，后端源码和配置见 [留言板说明](留言板/README.md)，不属于 Pages 静态包。

主站地址为 `https://sundollworld.com`。首页以一行品牌标题、冒险大厅和费伦日报组成入口区域，下方保留酒馆留言、骰子与拼图。冒险大厅的“开始冒险”或“进入我的冒险”始终指向个人主页；未登录时先在原账号页登录。右上角的普通“登录 / 注册”成功后回主站，已登录显示头像首字与昵称，菜单提供退出。关于页和公告页的账号菜单保留“我的主页”，首页通过冒险大厅进入，避免重复。账号地址为 `https://pl.sundollworld.com/account`，普通登录或注册成功默认回主站，可返回指定的合法主站页面；`#dashboard` 明确进入个人主页，收到邀请或管理链接时留在账号页完成操作。注册与找回密码在原网页输入六位邮箱验证码，个人主页提供房间列表、加入朋友房间、创建房间和房主分享玩家邀请。原工作区管理员入口不再作为主站常态链接。

跑团时双击项目根目录的 `启动桑哆尔之歌.command`，保持服务窗口运行；公网账号、游戏和留言写入还须确认隧道已连接。账号链接使用浏览器正常跳转，不在跳转前下载图片探测，也不弹出另一套等待窗口。`site-account.js` 统一处理账号菜单、身份状态和本机链接。localhost / 127.0.0.1 / [::1] 预览默认使用本机 `http://127.0.0.1:8090/account`，不要求公网隧道。

在 `主站/index.html` 修改首页文字，`主站/style.css` 修改样式，`主站/about.html` 修改 Sundoll 介绍。费伦日报数据在 `主站/announcements.json`：每条包含唯一 `id`、`date`（YYYY-MM-DD）、`title` 和 `body`（纯文本段落数组），可选 `background` 必须是构建清单中的公开图片。公告按日期降序、首页每页四条（`data-page-size`，脚本默认七条），同日保留原顺序；空正文只显示标题，有正文生成 `/news/<id>.html`。`announcements.js` 负责分页，`announcement-template.html` 只用于构建正文页，不公开上传；正文进行 HTML 转义。构建会同步首页的回退公告。

更新后在项目根运行 `python3 网站/build_site.py`，将输出的 `upload_zip` 上传到同一个 Pages 项目。构建采用公开文件清单，包含页面、公告及所需脚本和图片；静态资源采用内容哈希文件名，引用同步更新。HTML 与公告 JSON 每次重新验证，哈希资源可长期缓存。源文件仍在 `主站/` 编辑；默认生成目录与 ZIP 位于 `/private/tmp/`。指定路径可用 `--output /private/tmp/sundollworld-build --zip /private/tmp/sundollworld-build.zip`，输出目录必须为空。脚本检查本地引用、哈希和 ZIP 完整性；不要上传 README、构建脚本、临时预览或程序包。

首页骰子的 20 条奇幻事件在 `主站/site.js` 的 `events` 数组维护，每次掷出 1–20 并替换当前事件，结果不写角色或服务器。支持键盘与减弱动画偏好，长正文在结果卡片内滚动。背景原稿与制作交接保留在 `创作包/网站背景/2026-10-04/`。

`主站/puzzle.js` 负责“传奇画像”五乘五滑动拼图；二十四块图片和一个空位，通过五百次合法移动打乱，保证有解。相邻块可点击或用 Enter / Space 移动，完成后补全图片，可重新打乱。连续点击“打乱”十次、相邻间隔不超过 1.5 秒会复原图片；移动任一块或超时会重置计数。排列与步数仅存当前页面内存，刷新重新打乱。原图与交接在 `创作包/网站背景/2026-10-04/忒修斯拼图/`。

`主站/guestbook.js` 负责共享留言板“酒馆传声”。公开列表和回复立即匿名读取，不等账号服务；账号确认后再更新自己的点赞和删除状态。已登录时点“留言”展开正文表单，打开后按钮为“收起”，提交为“发布”。昵称由账号提供，不手填；正文最多五百个 Unicode 字符，作为纯文本显示。留言与回复分批分页，长文可展开，回复以“回复者 回复 对象”显示，同一级缩进。

留言、回复、点赞及删除均需有效账号会话。`主站/site-account.js` 从账号服务取得短期留言身份票；写操作强制重查身份，Worker 再复核会话有效性。按稳定账号作者身份识别有权删除的内容，同一账号可跨设备点赞和删除；不会按同名认领旧未绑定内容。自己的内容可通过垃圾桶确认删除，只有后端确认后才更新列表。草稿与提交编号按账号保存在当前页面内存，失败保留，原账号重试复用提交编号；切换账号不混用草稿。正文、点赞和回复记录保存在 D1。

当前 `guestbook-api` meta 为 `https://sundollworld.com`，留言请求使用同源 `/api/messages`；Worker 路由为 `sundollworld.com/api/messages*`。`account-api` 为 `https://pl.sundollworld.com`，对应 `_headers` 的 CSP 允许账号连接。本机隔离预览可用无路径、query、hash、userinfo 的 HTTP loopback `account-api` 临时端口；生产仅接受正式账号 origin。

新留言数据库执行 `留言板/schema.sql` 并绑定 `BOARD_DB`；已有数据库按 [留言板说明](留言板/README.md) 执行增量迁移，保留历史内容。账号服务和 Worker 的身份签名配置需一致，密钥不进入前端或 Pages 包。当前 `REVIEW_REQUIRED=false`，有效账号发布后直接公开；未配置时默认待审核。Pages 构建与 Worker 配置各自发布，线上版本与验收以以下有日期的记录为准。
