# 桑哆尔之歌

面向 D&D 跑团的本地主控台与浏览器玩家端，提供地图、棋子、角色背包、物品库、备团手册和音乐等功能。

本仓库保存完整的个人跑团工作区：**主程序、通用内容、战役进度和玩家角色**。下载后会带上仓库中的已有内容，并非空白发行版。运行不需要开发包或创作包。

## 下载与启动

1. 安装 [Python 3.9 或以上版本](https://www.python.org/downloads/)。Windows 安装时勾选 **Add Python to PATH**。
2. 使用 Git 克隆本仓库，或点击 **Code → Download ZIP**，将压缩包完整解压。地图和立绘较多，请等待下载完成。
3. macOS 双击根目录的 **启动桑哆尔之歌.command**；Windows 双击 **启动桑哆尔之歌.bat**。
4. 保持启动窗口运行，在自动打开的主控台首页选择战役。玩家通过主控台的“复制邀请链接”进入。

也可以在仓库根目录通过终端启动：

```sh
python3 程序包/主程序/launch_sundoll.py
```

Windows 可将 `python3` 换成 `py -3`。macOS 若启动器缺少执行权限，可运行 `chmod +x 启动桑哆尔之歌.command`。

## 仓库结构

```text
桑哆尔之歌/
├─ 启动桑哆尔之歌.command      macOS 启动入口
├─ 启动桑哆尔之歌.bat          Windows 启动入口
├─ README.md
└─ 程序包/
   ├─ 主程序/                 主控台、玩家端、服务与界面资源
   ├─ 通用包/                 通用棋子、物品与共享素材
   ├─ 战役包/                 地图、专属内容与各场冒险进度
   ├─ 玩家包/                 角色、伙伴、各角色背包与立绘
   └─ 运行数据/               工作区索引与模块协调记录
```

主程序、通用包、战役包和玩家包互相独立，运行数据负责连接它们。正式立绘和地图跟随所属模块保存。角色成长、装备、背包、当前血量与剩余资源跨战役延续；每个角色拥有独立背包，不设玩家公共仓库。

玩家以唯一的玩家账号名登录，账号下的角色允许同名。当前没有邮箱密码验证，知道玩家名字即可登录。

## 本地与公网联机

- **本机或可互通的同一网络**：不需要 Cloudflare。在根目录运行 `python3 程序包/主程序/launch_sundoll.py local` 即可仅启动本地服务。
- **异地玩家**：默认通过 Cloudflare Quick Tunnel 提供临时 HTTPS 入口，只有主持人电脑需要安装 `cloudflared`，玩家只需要浏览器。
- **安装 Cloudflare 客户端**：macOS 可执行 `brew install cloudflared`；Windows 可执行 `winget install --id Cloudflare.cloudflared`。也可按 [Cloudflare 官方说明](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)安装。平台专用的二进制文件不随 Git 仓库上传。
- **发送邀请**：确认启动窗口显示隧道已连接，再复制邀请链接。有效公网链接形如 `https://….trycloudflare.com/主控台/玩家.html?room=…`，重新启动隧道后可能变化。
- **网络要求**：Cloudflare 隧道需要访问其节点的 7844 端口。校园或单位网络可能限制连接；公网入口未就绪时，复制出的 IP 链接不保证异地可用。此时仍可使用本地功能。

不要同时运行多个公网启动窗口。主控台一直停在“检查存档”属于本地启动异常，不是正常等待 Cloudflare 的界面。

## 保存、迁移与更新

- 在主控台保存战役后再同步；GitHub 只包含已保存到文件的进度。
- 从一台电脑切换到另一台电脑前，先结束上一台的编辑，避免同时修改同一工作区。
- “冒险管理”可以导入、导出战役、玩家和通用模块。完整私人迁移优先使用其中的整套备份与恢复。
- 仓库不上传登录凭据、临时会话、运行缓存、协调数据库、恢复备份及本机日志。新副本启动时会从模块文件重建必要的运行记录，玩家需要重新登录。
- 已经在使用的电脑更新前，请先备份并关闭服务。只升级程序时替换 `程序包/主程序/`，保留自己的内容模块和运行数据；不要直接用整份下载内容覆盖已有进度。

更多操作见 [程序包使用说明](程序包/使用说明.md)。
