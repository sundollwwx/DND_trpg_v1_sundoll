# 桑哆尔之歌

网页版跑团工具。主站连接邮箱账号与个人主页；用户可以创建角色、以 DM 身份创建房间，或接受邀请，以玩家身份加入朋友的冒险。

账号直接拥有角色，一个角色一个背包和钱包。角色可跨房间沿用；房间保存地图、剧情与局内状态，同一角色同时只有一个活动房间可以修改其正式数据。

## 开始使用

- 已部署的网站：[sundollworld.com](https://sundollworld.com)。从“我的主页”选择角色和房间。
- 已配置的本机安装：macOS 双击 `启动桑哆尔之歌.command`，Windows 双击 `启动桑哆尔之歌.bat`，选择本机使用或公网联机。启动器不自动打开浏览器。
- 本机默认账号入口：`http://127.0.0.1:8090/account#dashboard`，实际端口以启动窗口为准。

**第一次检出源码或安装空白发行包**，先在 `程序包/主程序/` 配置自己的账号服务：

```sh
python3 manage_accounts.py init --origin https://play.example.com
python3 manage_accounts.py check
```

把示例域名替换成自己的账号域名。邮箱注册还需要 SMTP 发信设置与密钥；完整参数和配置顺序见 [部署与维护](开发包/docs/部署与维护.md)。`init` 只初始化空安装，不覆盖已有账号或存档。配置完成后，从项目根目录启动本机服务。

运行服务需要 Python 3.9 或以上版本。公网连通性与邮件投递分别依赖对应服务的实际状态；静态主站上线不等于房间服务在线。

## 源码结构

```text
桑哆尔的世界/
├─ 启动桑哆尔之歌.command / .bat   同一个启动菜单的两种平台包装
├─ 程序包/
│  ├─ 主程序/
│  │  ├─ server/                 账号、权限、房间与持久化
│  │  ├─ web/                    登录、注册与个人主页
│  │  ├─ 主控台/                 DM、玩家端及共用交互
│  │  ├─ shared/                 会话、规则、设计样式和素材缓存
│  │  └─ defaults/               新房间使用的公开默认资料
│  └─ 使用说明、目录导览、账号与角色规则
├─ 网站/                          公共主站与留言服务源码
└─ 开发包/                        测试、发行构建及维护工具
```

`程序包/运行数据/` 在本机安装后保存账号、角色与房间，**不进入源码仓库**。历史归档、私人备份、作者创作原稿和未采用候选同样留在本地。公共默认资料仅在新房间初始化时安装，升级程序不会覆盖已有房间的修改。


