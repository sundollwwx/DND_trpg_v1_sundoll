
# 程序包

这是可独立运行的工作区，包含主程序、通用包、战役包、玩家包和运行数据，不依赖开发包与创作包。

需要 Python 3.9 或以上版本。可双击仓库根目录的启动器，或进入 `主程序/` 双击其中的启动器。详细操作见 [使用说明](使用说明.md)。

### 免费公网联机

双击原来的“启动桑哆尔之歌”即可。当前电脑在 `运行数据/联机设置.json` 中选择了 `cloudflare`。Cloudflare 需要本机到其隧道节点的 7844 出站连接可用。主控台仍在本机打开，玩家使用主控台“复制邀请链接”。

启动窗口应保持打开。临时域名可能在重连后变化，届时请重新复制邀请链接。localhost.run 仅保留为手动备用方案：免费版有限速和域名时效，不适合当前大量地图和立绘的加载需求。

进入 `主程序/` 后，可用 `python3 launch_sundoll.py --tunnel-provider localhost-run` 手动选择备用通道，或 `python3 launch_sundoll.py local` 只启用本地联机。不要同时运行多个不同的公网启动窗口。

GitHub 不包含平台专用的 `cloudflared` 二进制文件；需要公网联机时请单独安装。macOS 可运行 `brew install cloudflared`，Windows 可运行 `winget install --id Cloudflare.cloudflared`。

### 按名称浏览棋子立绘

玩家包、战役包、通用包各模块中的 `棋子立绘/浏览立绘.html` 可直接双击打开，点击图片查看原尺寸，点击下载或复制对应角色文件夹导出。图片目录按角色名和形态名排列，并附身份短码以区分同名角色。

`资源/` 是模块正式原图；`棋子立绘/` 是自动维护的可读副本，不依赖创作包。新增、更新、改名、删除与归属变化通过程序操作后自动同步。不要手动覆盖生成的图片；要编辑，请先复制导出，完成后重新通过程序入库。
