# 程序包

这是网页版的运行工作区，**运行不依赖开发包与创作包**。日常使用根目录对应平台的统一启动器；主程序内的同名文件是独立发行时使用的模板。

- `主程序/`：Python 服务、账号页、DM、玩家端和共用界面素材。
- `运行数据/`：账号认证、全站角色与背包、房间及持久化协调记录。
- `运行数据/战役空间/<roomId>/`：各账号创建或加入的房间数据，按房间独立保存。
- `运行数据/历史归档/<归档名>/`：已有安装归档旧工作区时保留的差异内容，退出日常读写。新安装没有历史归档。

操作见 [使用说明](使用说明.md)，目录及存储边界见 [目录导览](目录导览.md)，角色规则见 [账号与角色规则](账号与角色规则.txt)。邮箱、隧道和服务配置统一见 [部署与维护](../开发包/docs/部署与维护.md)。

账号服务配置完成后，本机统一入口是 `http://127.0.0.1:8090/account#dashboard`。旧的无房间 DM／玩家地址转到个人主页；历史归档不作为服务启动。

新检出的源码没有作者账号和房间。首次使用先执行 `主程序/manage_accounts.py init --origin https://自己的账号域名`，按部署说明配置发信，再通过统一启动器进入个人主页。公开默认规则在 `主程序/defaults/`。
