# 音乐播放结构与主控台操作

更新：2026-09-24。播放器已经接入主控台。新增同名音频更新的缓存版本处理，以及六种休息场景的转场配乐，详见 [重审与休息音频](播放器重审与休息音频.md)。

## 使用方式

1. 点击左侧工具栏「场景 → 音乐」打开播放器。顶部默认选中「浏览器播放」，常用网站中的「B 站」在新标签页打开；本地曲库位于播放器底部。
2. 按场景分类、曲目来源或曲名搜索找歌。分类只表示音乐适用的气氛，与地图没有绑定关系。
3. 没有音乐播放时，点选曲目查看名称、分类和来源，再选择「仅我试听」或正式播放。已有文件音乐时，点击另一首会直接切换；加载开始后弹窗上方和左侧音乐卡立即显示目标曲名，失败则恢复原曲标题。
4. 未联机时，正式按钮为「在本机播放」；开启玩家模式后为「给全员播放」。
5. 点击「收起」、弹窗外侧或 Escape 关闭播放器。正式音乐继续，左侧音乐卡保留当前曲名、暂停/继续和停止；本机试听随弹窗关闭而结束。

打开弹窗、改变分类、切换地图、回合或工作区都不会自动换歌。页面刷新不会自动恢复播放。

## 文件位置

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 通用成品 | `asset/音乐/通用/<场景分类>/` | 所有战役可用 |
| 战役成品 | `asset/音乐/战役/<存档中的实际战役目录>/<场景分类>/` | 只在对应战役曲库中显示；不是地图配乐绑定 |
| 制作历史 | `创作包/音乐制作/通用/<曲名>/` 或 `创作包/音乐制作/战役/<战役目录>/<曲名>/` | 完整提示词、版本、候选与母带；不进入正式曲库 |
| 休息转场短声 | `asset/界面/休息动画/音频/` | 随长短休动画播放一次，不进入背景音乐列表 |
| 临时广播文件 | 根目录 `音乐缓存/` | 程序运行缓存，不作为正式素材库 |

本版没有地图配乐、地图推荐或战役音乐编排字段，不需要修改地图或战役存档。

## 场景分类

默认显示：**主题、城镇、探索、悬疑、战斗、首领、休息、剧情**。

- 文件夹决定分类。例如 `通用/城镇/酒馆·炉火未熄.mp3` 显示为「城镇」。在分类下继续分子文件夹，仍归入上一级场景。
- 兼容旧目录：`环境` 显示为「探索」，`Boss` 显示为「首领」。其他自定义一级场景文件夹也会出现在分类列表。
- 正式曲库根部不再散放音频。《冒险》《决战》位于 `通用/待分类/`；《城镇·灯下旅人》位于 `通用/城镇/`。
- 临时选择的文件进入「临时」分类，多次选择追加到本次页面会话，刷新页面后不保留这份临时列表。
- 长短休的 2.2 / 4.4 秒声音是界面转场，不作为背景音乐参与搜索、队列或场景顺序循环。

正式音乐位于 `程序包/通用包/本地资料/资料/音乐/`，制作历史保留在 `创作包/音乐制作/`。表中的 `asset/` 是程序兼容资源路径。扫描器递归扫描正式音乐目录，给子文件夹命名「草稿」或「母带」并不会排除其中音频。

## 播放规则

| 操作 | 本机 | 玩家端 |
| --- | --- | --- |
| 点选、搜索、分类筛选 | 只改变列表与详情 | 不变 |
| 仅我试听 | 独立试听通道；暂时静音本机正式音乐，原曲时间继续前进 | 正式音乐继续 |
| 结束试听或收起弹窗 | 恢复本机正式音乐的声音 | 不变 |
| 播放选中曲目 | 从新曲曲首播放；加载失败保留原曲 | 已联机时发送新曲指令 |
| 暂停/继续 | 保留当前位置 | 同步暂停/继续 |
| 停止 | 正式音乐停止并归零，保留当前曲目供重新播放；结束试听 | 同步停止 |
| 拖动进度 | 拖动中预览位置，松手提交 | 松手后同步最终位置 |
| 我的音量 | 调整本机文件音乐与试听 | 不改变其他玩家设置 |

三种播放方式：

- **单曲循环**：默认设置，当前歌曲反复播放。
- **播放一次后停止**：到结尾停止，适合剧情和尾声。
- **同场景顺序循环**：按开始播放时同场景曲目组成的顺序切换；没有其他同类时循环当前曲目。

上一首/下一首也只在当前歌曲的同场景曲目内切换。这个顺序在手动播放一首曲目时建立，后续筛选、搜索不会改变它；刷新曲库只移除已失效项，不把新曲自动插入正在播放的顺序。不同来源中同分类的曲目可以一起播放。

声音状态与广播状态分开。只有服务器确认后显示「已发送房间指令」；这不代表已经验证每位玩家都听见。浏览器阻止玩家自动播放时，玩家仍需点击「启用声音」。

## 外部音源：Mac 网易云客户端

曲库当前保留《冒险》《城镇·灯下旅人》《决战》。外部音源是实时转播，不会导入网易云歌单或读取下载文件。

1. 在 Chrome / Edge 中打开本机主控台并开启联机。
2. Mac 桌面软件可通过 BlackHole 等虚拟音频设备接入。在「音频 MIDI 设置」建立包含 BlackHole 与耳机的多输出设备，将网易云声音送到此设备。
3. 在播放器顶部选择「输入设备」，点击「读取设备」，选择 BlackHole，点击「连接输入设备」。浏览器把音频输入权限称为麦克风权限，选普通麦克风会收录环境声音。
4. 在网易云里播放、切歌。这里的暂停、继续只控制转播，停止会释放采集与玩家连接，不控制网易云本身。
5. 可以改选「系统声音」并点击「连接系统声音」尝试浏览器直接共享；实际能否捕获取决于系统和浏览器共享窗口是否提供音频选项。网页版音乐使用「浏览器播放 → 连接浏览器」，在浏览器共享窗口勾选共享音频。

多输出设备可能同时转播其他应用声音；主控台不再次播放输入音频，避免双重监听。主控台「我的音量」控制文件音乐，外部音源音量在原软件调节，玩家始终可自行调音量。

只有捕获到音频后才切换音源。取消、拒绝或选择没有音频的屏幕会保留原有文件音乐。点击「停止」或切回文件音乐会取消尚未完成的采集请求；迟到的授权结果不会恢复广播。

「重新同步」重发当前房间播放状态，直播时会重建玩家连接。连接人数表示 WebRTC 已连接，不代表逐人确认听感。目前沿用 STUN 点对点传输，没有 TURN 中继；某些网络可能无法直连。

参考：[BlackHole 官方多输出设备说明](https://github.com/ExistentialAudio/BlackHole/wiki/Multi-Output-Device)、[Chrome 声音共享选项](https://developer.chrome.com/docs/web-platform/screen-sharing-controls)。

## 持久化和实现边界

音频与制作记录在磁盘；音量、播放方式保存在各自浏览器。选中项、分类筛选、临时文件和当前播放顺序只属于页面会话，不写入地图或战役存档。

项目曲库继续沿用服务器的目录扫描与流式音频接口。当前服务器以 `BGM_STATE` 为房间音乐权威状态，完整快照中的 `_bgm` 也从 `BGM_STATE` 生成，专用事件与完整快照同源。文件音乐指令串行发送，过期上传或切歌请求不能覆盖新的停止/播放操作。

切换战役会刷新可用曲库；当前曲仍可用则继续播放，已不在曲库的曲目停止。不会按新地图或新战役自动选择下一首。

制作档案仍通过项目文件查看。本版弹窗展示文件位置，不读取或编辑长提示词；完整档案入口见 [音乐制作说明](../../../../../创作包/音乐制作/README.md)。交叉淡化、独立环境声与一次性音效尚未实现。

## 模块维护与验证

- 主控台文件播放、试听、队列与统一广播队列：`主控台/host/music.js`（标记区外的播放器代码）。
- 外部音源采集与玩家连接源模块：`主控台/host/live-audio.js`。
- 玩家文件／直播接收与同步源模块：`主控台/player/music.js`。
- 修改源模块后运行 `python3 开发包/构建/构建音乐模块.py`，分别打包进既有的 `host/music.js` 和 `player/player.js`。不要手改 `BEGIN BUNDLED MUSIC MODULE` 区域。
- 继续使用已允许访问的脚本入口，无需放宽静态文件访问权限或重启服务。更新后保存当前战役，再刷新主控台和玩家页面。
- 关键回归：`test_music_player.cjs`、`test_live_audio.cjs`、`test_player_music.cjs`。
