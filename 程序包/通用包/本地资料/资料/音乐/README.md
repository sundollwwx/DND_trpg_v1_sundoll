# 正式播放曲库

这里仅保存会出现在主控台音乐播放器中的完整背景音乐。主控台通过「左侧工具栏 → 资源 → 音乐 → 选择歌单 / 打开完整播放器 → 刷新」扫描本目录。

## 目录

| 位置 | 用途 |
| --- | --- |
| `通用/<场景>/` | 所有战役共用的正式背景音乐 |
| `战役/<战役ID>-<战役名>/<场景>/` | 只在对应战役中显示的正式背景音乐 |
| `通用/待分类/` | 用途尚未试听确认的既有可播放旧曲 |
| [音乐播放结构.md](音乐播放结构.md) | 播放器操作、分类与播放规则 |
| [音乐制作资料](../../../../../创作包/音乐制作/README.md) | 提示词历史、乐谱、候选、小样与母带 |
| [休息动画音频](../../../../主程序/asset/界面/休息动画/音频/) | 长短休界面的一次性转场短声，不进入音乐播放器 |

标准场景为：`主题`、`城镇`、`探索`、`悬疑`、`战斗`、`首领`、`休息`、`剧情`。新目录统一使用这些中文名称；扫描器仍兼容旧项目中的 `环境` 和 `Boss`。

当前正式背景音乐仅保留《冒险》《城镇·灯下旅人》《决战》，按场景整理如下：

| 场景 | 数量 | 内容 |
| --- | ---: | --- |
| 城镇 | 1 | 城镇·灯下旅人 |
| 待分类 | 2 | 冒险、决战 |

空的标准场景目录只保留结构占位。战役目录在真正加入专属成品时再创建，不预建空战役树。

## 放入一首新音乐

1. 在 `创作包/音乐制作/通用/<曲名>/` 或 `创作包/音乐制作/战役/<战役目录>/<曲名>/` 保存制作记录与历次提示词。
2. 候选试听、循环检查和用户确认完成后，把采用版复制到本目录对应的场景文件夹。
3. 正式文件使用易读曲名，例如 `酒馆·炉火未熄.mp3`；版本号保留在制作目录的小样与候选文件中。
4. 更新制作记录中的正式路径，再刷新主控台曲库。

常用播放格式建议 MP3 或 M4A。扫描器也识别 WAV、OGG、FLAC、AAC、OPUS 和 WebM；浏览器是否能解码仍取决于平台。播放器的单曲循环不保证音频首尾无缝，入库前需要实际试听。

不要把草稿、母带或一次性界面音效放入本目录。扫描器会递归收录这里的音频；制作内容统一放在 `创作包/音乐制作/`，界面专用短声与对应界面资源放在一起。
