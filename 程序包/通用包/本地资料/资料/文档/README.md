# 战役资料存储

主控台的“资料 → 战役资料”会读取当前战役模块及通用资料模块中，与当前战役匹配的文件夹：

```text
资料/文档/战役/<战役ID>-<战役名称>/
```

例如“风骸岛之龙”的资料放在：

```text
程序包/战役包/c286-风骸岛之龙/资料/文档/战役/c286-风骸岛之龙/
```

这里保存原始 `.docx` 和 `.pdf` 文件。放入文件后，在主控台切换到对应战役，再点击“刷新”即可读取。Word 文件会转换为安全的只读结构预览；PDF 使用浏览器内置阅读器。原文件不会被修改。

通用文档放在本模块的 `资料/文档/战役/` 下；战役专属文档优先放进所属战役模块，随该战役一起导出。资料库是 GM 私有工具，不写入联机状态，也不会同步到玩家端。项目服务器会阻止这些目录被普通静态网址直接读取，所有预览和原文件下载都通过本机主控台接口完成。
