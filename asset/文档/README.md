# 战役资料存储

主控台的“资源 → 战役资料”只读取当前战役对应的文件夹：

```text
asset/文档/战役/<战役ID>-<战役名称>/
```

例如“风骸岛之龙”的资料放在：

```text
asset/文档/战役/c286-风骸岛之龙/
```

这里保存原始 `.docx` 和 `.pdf` 文件。放入文件后，在主控台切换到对应战役，再点击“刷新”即可读取。Word 文件会转换为安全的只读结构预览；PDF 使用浏览器内置阅读器。原文件不会被修改。

资料库是 GM 私有工具，不写入联机状态，也不会同步到玩家端。项目服务器会阻止这个目录被普通静态网址直接读取，所有预览和原文件下载都通过本机主控台接口完成。
