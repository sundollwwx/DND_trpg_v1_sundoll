# 决战·赤旗破阵 · v002 制作记录

- 日期：2026-09-06；当前主控台播放版：v002-a；范围 / 场景：通用 / 首领。
- 用户原始反馈：「这几首决战的音乐感觉不够大气，激情」。
- 本版方向：强化管弦齐奏、节奏推进与高潮，保留原曲旋律动机；仍为原创本机乐器音源渲染小样，待用户试听。

## 相对 v001 的实际改动

- 速度：144 → 152 BPM；拍号：4/4 → 4/4。
- 时长：113.684 秒；结构：宣告8 / 主题16 / 展开16 / 低潮4 / 蓄势4 / 全奏高潮16 / 强势回环8。
- 音符事件：1819 → 3273；新增铜管群齐奏、强化高弦与低音鼓组。
- 主题从开头进入，低潮缩为四小节，再经四小节滚奏推向十六小节全奏高潮。
- 提升实际 MIDI 力度与乐器配比；更密的低弦节奏、鼓点和跨八度旋律共同扩大配器。
- 和声：A: Dm–Dm/C–Bb–F/A–Gm–Dm/F–Eø–A；B: Bb–F–C–Dm–Gm–Bb–Eø–A。
- 乐器：低弦节奏、宽弦乐群、铜管群、圆号主旋律、大提琴低音、定音鼓、战鼓军鼓与镲、高弦颤奏、钢琴脉冲。
- v001 乐谱、简报、MIDI、检查报告、候选与母带已按 SHA-256 核对未改动；旧集中小样也与 v001 候选一致。
