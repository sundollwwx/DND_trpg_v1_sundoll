# 音乐制作档案

这里保存每首音乐的制作过程。正式播放音频放在同级的 [音乐目录](../音乐/README.md)，本目录不会被当前曲库扫描器列入曲库。

## 固定存放方式

```text
音乐制作/
├── 模板/单曲制作记录.md
├── 小样/<批次>/<曲名>-v001.m4a（集中试听与版本留档）
├── 通用/<曲名>/
│   ├── 制作记录.md
│   ├── 候选/v001-a.mp3、v001-b.mp3、v002-a.mp3（需要时创建）
│   └── 母带/v002-定稿.wav（需要时创建）
└── 战役/<存档中的实际战役目录>/<曲名>/
    └── 同上
```

每首曲目复制一份 [单曲制作记录模板](模板/单曲制作记录.md)。记录中的「提示词历史」保留**每一次实际提交的完整原文**：v001、v002 顺序追加，旧版不覆盖、不只写「同上」或「再史诗一点」。制作工具、模型、参数、生成日期、候选文件与采用结果一并记录。

使用参考音乐时，记录来源链接或本地参考路径及使用方式；来源或授权情况不清楚就写「未核实」。不要根据文件名推断作者、生成工具或音乐特征。

定稿后，在记录里标明采用的提示词版本、候选编号、剪辑处理和正式播放路径。正式目录保留当前采用版；之前采用过的音频留在制作目录中，提示词与版本记录继续追加。后续只改混音或剪辑也记录版本关系。
