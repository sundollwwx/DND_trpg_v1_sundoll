# AI 文生图场景生成流程

本流程只用于通过 AI 文生图生成完整场景图片，不用于地图工坊的地块绘制、材质拼接或 `.地图.json` 制作。

AI 场景图分为两类：

| 类型 | 主要用途 | 镜头 | 网格处理 |
| --- | --- | --- | --- |
| 战术俯视图 | 战斗、探索、移动与距离判断 | 严格垂直俯视、正交感 | AI 不画网格；导入主控台后叠加网格 |
| 叙事场景图 | 地点揭示、过场、气氛与剧情展示 | 根据叙事目的自由选择 | 关闭网格 |

两类图片都是普通 PNG、JPG 或 WebP。它们可以直接载入主控台，不需要经过地图工坊，也不要伪装成地图工坊导出的 `.地图.json`。

## 一、生成前填写场景单

每次生成前先填写以下信息。没有确定的项目可以删掉，不要让模型自行补完会影响玩法的结构。

```text
场景名称：
图片类型：战术俯视图 / 叙事场景图
战役与地点：
场景用途：本图出现时玩家要理解、感受或完成什么
地点类型：室内 / 城镇 / 野外 / 地下 / 异界 / 其他
时间与天气：
核心环境：地面、墙体、植被、水体、建筑材料
固定地标：祭坛、桥、巨树、王座、裂隙等
空间关系：入口、出口、道路、房间、区域之间的位置关系
剧情状态：完好、废弃、燃烧、战后、被占领等
主色与照明：
必须出现：
不得出现：
连续性要求：与哪些既有地点、阵营或前一张图片保持一致
```

先确定空间与用途，再补风格词。影响行动路线、入口数量、地标位置或剧情事实的内容必须写在场景单中，不能只靠“宏大”“神秘”等形容词暗示。

## 二、战术俯视图流程

### 1. 先确定画幅、格数与比例

推荐使用每格 `64px` 的基准，生成后在主控台把「每格像素」设为 `64`：

| 最终图片尺寸 | 可用方格 | 适合场景 |
| --- | --- | --- |
| 1024×1024 | 16×16 | 房间、小型遗迹、小规模遭遇 |
| 1536×1024 | 24×16 | 横向道路、营地、中型战场 |
| 1024×1536 | 16×24 | 长廊、峡谷、纵深探索 |

图片宽高应当能被每格像素整除，左上角就是网格起点。需要其他尺寸时，先决定整数格数，再用“格数 × 每格像素”得到最终尺寸。

### 2. 把场景写成可行走结构

战术图至少明确：

- 玩家可能进入和离开的方向。
- 可行走区、困难地形、阻挡区与危险区。
- 墙、门、桥、悬崖、水岸等边界的位置。
- 掩体、制高点、狭窄通道和开阔区。
- 会影响遭遇的固定地标，以及它们之间的相对位置。

使用“西侧入口通向中央空地，北侧有一座窄桥”这类空间描述。不要依赖“复杂迷宫”“丰富战术性”等抽象词。

### 3. 使用战术俯视图提示词

复制以下模板并替换方括号内容：

```text
任务：生成一张 AI 文生图战术地图背景，用于跑团战斗、探索、移动和距离判断。这是普通场景图片，不是地图编辑器截图。

场景：[场景名称与一句话概述]。
地点与状态：[地点类型、时间、天气、完好或破坏状态]。
空间布局：[入口、出口、道路、房间、区域与固定地标的明确相对位置]。
地形与材质：[地面、墙体、植被、水体、建筑材料、困难地形与危险区]。
战术信息：[掩体、阻挡区、制高点、狭窄通道、开阔区]。

镜头：严格 90 度垂直向下俯视，正交投影视觉，无地平线，无透视汇聚，无倾斜镜头。所有地面、墙体、门、桥、家具和地标保持统一比例；可行走区域边界清楚，不能被屋顶、树冠、烟雾或强光大面积遮挡。

画幅：[1024×1024 / 1536×1024 / 1024×1536]，[16×16 / 24×16 / 16×24] 个方格的空间规划，每格按 64px 对齐。图片边缘与空间边界整齐，方便从左上角叠加方形网格。

视觉：西幻规则书与高质量战术地图质感，[主色与照明]；轮廓和材质在缩小查看时仍然清楚，装饰细节服从可行走结构和战术辨识。

限制：不要生成任何网格线、坐标、比例尺、文字、标签、罗盘、图例、UI、边框、签名或水印。不要生成玩家角色、敌人、NPC、坐骑或可移动单位；这些会在主控台中单独放置。不要使用等距视角、鸟瞰斜视、侧视墙面、电影透视或广角畸变。不要让阴影、特效、雾气或装饰遮住行动路线和关键边界。
```

### 4. 战术图验收

生成后依次检查：

- 镜头是否真正垂直，没有看见建筑立面、地平线或远近透视。
- 图片尺寸是否与预定格数和每格像素对应。
- 从左上角叠加网格后，门、走廊、桥和掩体是否能自然落格。
- 所有入口、出口、可行走区、阻挡区和危险区是否一眼可分。
- 是否混入网格、文字、单位、UI、边框或水印。
- 缩小查看时，主要区域和路线是否仍然清楚。

布局不合格时优先重生成，不要依靠后期涂改修复错误的入口、墙体或透视。

### 5. 导入并叠加网格

1. 将成图保存到 `asset/地图/战役地图/<战役名>/`，建议命名为 `<地点>·战术俯视.png`。
2. 打开主控台，进入顶部「🗺️ 地图」并点击「＋ 载入地图」。
3. 选择成图，在导入确认页开启「显示网格」，将「每格像素」设为生成时使用的数值，标准值为 `64`。
4. 导入后检查左上角、右下角和主要门口的网格对齐；必要时先在图像软件中裁切或缩放到正确尺寸，再重新导入。
5. 开启棋子吸附，用 1×1 和 2×2 棋子分别检查门、道路、桥梁和房间宽度。

AI 战术图在主控台中属于普通图片地图。它的网格大小仍可调整；地图工坊生成的地图则由 `.地图.json` 固定网格，两者不要混用。

## 三、叙事场景图流程

### 1. 先确定镜头目的

每张叙事图只承担一个主要目的：

- 建立镜头：第一次展示地点全貌与规模。
- 到达镜头：从角色接近地点的方向展示入口和第一印象。
- 事件镜头：突出正在发生的仪式、灾难、冲突或异变。
- 线索镜头：突出一个地点、物件或环境异常，但不替玩家解释结论。
- 气氛镜头：表现休整、压迫、宁静、危险临近等情绪。

先写清玩家此刻应当看见什么，再选择平视、低角度、高角度、过肩、广角全景或近景。自由视角不等于随机视角。

### 2. 使用叙事场景图提示词

复制以下模板并替换方括号内容：

```text
任务：生成一张 AI 文生图叙事场景插画，用于跑团中的地点揭示、剧情过场或气氛展示。这是普通场景图片，不是战术地图，也不是地图编辑器截图。

场景：[场景名称与此刻发生的事情]。
叙事目的：[建立地点 / 表现到达 / 展示事件 / 呈现线索 / 营造气氛]。
地点与状态：[地点类型、时间、天气、历史痕迹、完好或破坏状态]。
必须看见：[核心地标、环境线索与剧情事实]。
空间连续性：[与既有地图或前一张场景图必须一致的材料、方向、颜色、建筑和地标]。

镜头：[平视 / 低角度 / 高角度 / 过肩 / 广角全景 / 近景]，[镜头高度、朝向和景别]。画面由前景、中景和背景构成，视觉焦点是[唯一主要焦点]；视线通过[道路、光线、建筑或人物朝向]引向焦点。

视觉：西幻叙事插画与电影感概念设计，[主色、照明与气氛]；材质、天气和光影共同服务于当前剧情。即使缩小展示，也能先看懂地点、焦点和情绪，再看见次要细节。

角色处理：[无人场景 / 只出现远景剪影 / 出现指定角色及其位置、动作与外观]。没有明确要求时不要自行添加主角、敌人或战斗。

画幅：[16:9 / 3:2 / 4:3 / 1:1]，建议长边至少 1536px。

限制：不要网格、坐标、比例尺、文字、字幕、标签、罗盘、图例、UI、边框、签名或水印。不要把画面做成俯视战术地图、平面图、地图编辑器界面、拼贴、多格分镜或概念设定表。不要添加会提前揭示真相的未要求内容。
```

### 3. 叙事图验收

生成后依次检查：

- 第一眼是否能看懂地点、唯一主要焦点和当前情绪。
- 镜头是否符合叙事目的，画面是否有清楚的前景、中景和背景。
- 核心地标、环境状态与剧情事实是否正确。
- 是否擅自添加角色、敌人、文字或会剧透的元素。
- 与同一地点的战术图及前后场景图是否保持材料、地标、方向和主色连续。
- 缩小到常用展示尺寸时，焦点是否仍然明确。

### 4. 保存与使用

1. 将成图保存到 `asset/地图/战役地图/<战役名>/`，建议命名为 `<地点>·叙事·<镜头用途>.png`。
2. 需要在跑团台展示时，通过顶部「🗺️ 地图」作为普通图片载入，并在导入确认页关闭「显示网格」。
3. 叙事图不设置战术比例，不使用棋子吸附来验证构图。
4. 同一地点需要多张图片时，在文件名中使用稳定镜头用途，例如「建立」「到达」「异变」「战后」，不要只写“版本1、版本2”。

## 四、同一地点的双图配套

同一地点同时需要战术图和叙事图时，先建立一份共同的场景单，再分别生成。两张图应共享：

- 建筑材料、地面类型、天气、时间与主色。
- 入口方向、核心地标数量和彼此关系。
- 地点当前状态与已经发生的破坏。
- 阵营符号、文化样式和关键环境线索。

战术图负责可操作空间，叙事图负责角色在空间中的感受。叙事图可以选择任意镜头，但不能改变战术图已经确定的门、桥、祭坛、道路和其他剧情关键结构。

推荐先生成并确认战术俯视图，再把已确认的空间结构摘要和参考图一起用于叙事图生成。若叙事图先完成，则在制作战术图前提取其中的固定地标与材料，避免两张图表现成两个不同地点。

## 五、最终归档检查

- 文件属于 AI 文生图，并以普通图片保存，没有改写成 `.地图.json`。
- 文件名能区分「战术俯视」或「叙事镜头」。
- 战术图无内置网格，主控台叠加网格后结构可用。
- 叙事图关闭网格，镜头目的和视觉焦点明确。
- 同一地点的双图在材料、地标、方向、时间和剧情状态上保持一致。
- 原图已经放入对应战役文件夹，并随战役存档验证过实际显示效果。
