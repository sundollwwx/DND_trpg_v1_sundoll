# 战役封面制作 Prompt

本文件是之后制作战役封面的固定规范。主控台保存的标准封面为 **1600×900，严格 16:9 横向画幅**；玩家端也按完整 16:9 比例展示。不要改成超宽银幕、3:2、4:3 或方形画幅。

## 通用 Prompt

```text
生成一张明亮、精致、有叙事感的奇幻 TRPG 战役封面插画。

战役名称与主题：[填写战役名称、地点、冲突和气氛]
主要场景：[填写环境]
主要角色或视觉焦点：[填写主体]
色彩与光线：[填写主色调；默认采用清晰、明亮、有层次的电影光线]

画幅要求：严格 16:9 横向构图，目标尺寸 1600×900；输出必须保持 16:9，不使用超宽银幕比例，不添加黑边。
构图要求：完整利用 16:9 画面；主要视觉焦点放在中央 60% 区域；画面四周保留自然延展的环境；左下方与底部约 18% 区域避免放置脸部、关键道具和必须辨认的细节，以便主页叠加战役名称。
风格要求：高质量奇幻插画，细节清晰，远近层次明确，缩小到主页卡片后仍能一眼辨认主题。
禁止内容：任何文字、标题、徽标、界面元素、水印、签名、可见边框、拼贴分格或白边。
```

## 验收标准

- 图片像素比例必须为 `16:9`；推荐直接输出 `1600×900`，或使用更高分辨率的等比例尺寸。
- 在完整画面中检查一次，不应依赖额外裁切才能成立。
- 缩小预览时，战役主题和主体轮廓仍应清楚。
- 左下方的主页文字覆盖后，不应挡住人物面部或关键情节。
- 上传主控台后，再分别检查主控台主页和玩家端主页；两端都应保持同一 16:9 构图。
